# Chinese Engineers Relational Database

This repository contains a Shiny dashboard built for exploring, querying, and visualizing data from the **Chinese Engineers Relational Database (CERD)**.  

The dashboard can be found at [https://dhi.ust.hk/cerd](https://dhi.ust.hk/cerd).

The dashboard provides an interactive, web-based interface for social historians, digital humanities scholars, and other researchers interested in the networks, careers, and institutional pathways of engineers in modern China.
